# Changelog

## 0.3.1.0 — beta

- Show the auto-return countdown on the Return key.
- Allow immediate manual return while counting down.
- Cancel automatic return when leaving the Dock.

## 0.3.0.2 — beta

- Use the property inspector registration context when saving settings.
- Save input changes immediately and provide an explicit Save button.
- Real-host settings persistence remains a release verification item.

## 0.3.0.1 — beta

- Use English for plugin actions, settings and the sharing guide.

## 0.3.0.0 — beta

- Add optional per-key auto-return delay; disabled by default.

## 0.2.0.4 — beta

- Display both bundled profiles as Mac Dock while retaining their routing identifiers.

## Earlier beta work

- Add a sandboxed native runtime and running/foreground app indicators.
- Provide separate single-profile archives for hardware and Mobile.
- Fix host rejection of archives containing multiple predefined profiles.

## Known upgrade issue

Stream Deck may retain a stale return destination after an update. Fully quitting and reopening Stream Deck resolved this in user testing. A permanent automatic recovery fix has not been established.
